On-Page SEO
On-page SEO optimises individual webpages so search engines can understand them and users can find useful information.
Key elements:
• Title tags and meta descriptions
• Headings and content
• URLs and internal links
• Images and media
• Search intent and keyword relevance

Example: Improve a service page so it clearly explains the service and targets relevant searches.

Title Tags & Meta Descriptions
Title tag: The page title that can appear in search results and browser tabs.
Meta description: A short summary that may appear beneath the title in search results.
Best practices:
• Make each page unique and accurate
• Include the primary topic naturally
• Write clearly to encourage relevant clicks
• Avoid keyword stuffing

Example title: SEO Services for Small Businesses | Brand Name

Headings & Content Structure
Headings organise content for readers and help search engines understand page sections.
Best practices:
• Use a clear main H1 heading
• Use H2s for major sections and H3s for subsections
• Keep the structure logical
• Make headings descriptive
• Break long text into readable paragraphs and lists

Example: H1: Beginner’s Guide to SEO → H2: Keyword Research → H3: Finding Keyword Ideas

URL Optimisation
A good URL is clear, concise, descriptive, and easy to understand.
Best practices:
• Include the page topic when useful
• Use hyphens between words
• Avoid unnecessary parameters and long strings
• Keep URLs lowercase where possible
• Avoid changing established URLs without a plan

Better: example.com/seo-services
Less clear: example.com/page?id=12345

Image Optimisation Linking
Optimised images support accessibility, user experience, and page performance.
Best practices:
• Use descriptive file names
• Write useful alt text for meaningful images
• Compress images and use suitable dimensions
• Use modern formats such as WebP or AVIF where supported
• Lazy-load below-the-fold images when appropriate
• Avoid lazy-loading the main above-the-fold image


Content Optimisation
Content optimisation improves a page’s usefulness, relevance, clarity, and alignment with search intent.
Best practices:
• Answer the user’s main question
• Cover relevant subtopics
• Use keywords naturally
• Add examples, evidence, and original insights
• Keep information accurate and up to date
• Make content easy to scan

Goal: Help the user, not just include keywords.


Keyword Mapping
Keyword mapping assigns target keywords and search intent to the most appropriate pages.
Example:
• Homepage → Digital marketing agency
• Service page → SEO services
• Blog post → How SEO works
• Product page → Women’s running shoes
Best practices:
• Give each page a clear primary topic
• Map supporting terms where relevant
• Avoid competing pages for the same intent unnecessarily

Crawling & Indexing
Crawling: Search engine bots discover and access URLs.
Indexing: Search engines process a page and may store it in their index.
Remember:
• A crawled page is not always indexed
• An indexed page is not guaranteed to rank
• Important pages should be internally linked and accessible
• Check accidental blocks, noindex directives, and server errors

Process: Discover → Crawl → Process → Potentially Index → Rank
